Poaster provides a `llms.txt` file for AI agents and LLMs to discover and understand the API programmatically.

## What is llms.txt?

[llms.txt](https://llmstxt.org/) is a convention for providing machine-readable documentation that AI agents can fetch and use to understand an API without scraping HTML pages. It's served as plain text at a well-known URL.

## Poaster's llms.txt

Our llms.txt is available at:

```
https://poaster.app/docs/llms.txt
```

It contains:

- A brief description of Poaster and the API
- The base URL and authentication method
- A summary of all available endpoints with HTTP methods, paths, and descriptions
- Common request/response patterns
- Error codes

## How AI Agents Can Use It

1. **Fetch** `https://poaster.app/docs/llms.txt`
2. **Parse** the endpoint descriptions
3. **Construct** API calls based on the documented parameters
4. **Handle** errors according to the documented error codes

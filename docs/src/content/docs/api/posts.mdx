Posts are the core content object in Poaster. Each post contains text (or a thread of text parts) and moves through statuses: `pending` → `approved` → `sent`. The API gives you full control over this lifecycle.

## Post Statuses

| Status | Description |
|--------|-------------|
| `pending` | Newly created, awaiting review |
| `approved` | Approved and queued for publishing |
| `rejected` | Rejected, will not be published |
| `sent` | Successfully published to social media |

---

## Create a Post

```http
POST /v1/websites/:website_id/posts
```

Creates a new post. If the website has `auto_approve_posts` enabled, the post is automatically approved.

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `website_id` | integer | Yes | The website ID (in the URL path) |
| `content` | string | Yes | The post text |
| `url` | string | No | Source URL for the post. Defaults to the website's `base_url` |

### Code Examples

<Tabs>
<TabItem label="cURL">

```bash
curl -X POST https://my.poaster.app/v1/websites/1/posts \
  -H "Authorization: Bearer po_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Just shipped a new feature that makes AI agents 10x more useful. Thread below 🧵"
  }'
```

</TabItem>
<TabItem label="Python">

```python
import requests

response = requests.post(
    "https://my.poaster.app/v1/websites/1/posts",
    headers={
        "Authorization": "Bearer po_live_your_api_key",
        "Content-Type": "application/json",
    },
    json={
        "content": "Just shipped a new feature that makes AI agents 10x more useful. Thread below 🧵"
    },
)
print(response.json())
```

</TabItem>
<TabItem label="Ruby">

```ruby
require 'net/http'
require 'json'

uri = URI('https://my.poaster.app/v1/websites/1/posts')
request = Net::HTTP::Post.new(uri, 'Content-Type' => 'application/json')
request['Authorization'] = 'Bearer po_live_your_api_key'
request.body = {
  content: 'Just shipped a new feature that makes AI agents 10x more useful. Thread below 🧵'
}.to_json

response = Net::HTTP.start(uri.hostname, uri.port, use_ssl: true) do |http|
  http.request(request)
end
puts response.body
```

</TabItem>
<TabItem label="JavaScript">

```javascript
const response = await fetch("https://my.poaster.app/v1/websites/1/posts", {
  method: "POST",
  headers: {
    Authorization: "Bearer po_live_your_api_key",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    content:
      "Just shipped a new feature that makes AI agents 10x more useful. Thread below 🧵",
  }),
});
const data = await response.json();
console.log(data);
```

</TabItem>
</Tabs>

### Response

```json
{
  "success": true,
  "message": "Post created successfully!"
}
```

### Errors

| Status | Cause |
|--------|-------|
| `401` | Invalid or missing API key |
| `403` | Website belongs to another user |
| `422` | Content is blank |

## Update a Post

```http
PATCH /v1/websites/:website_id/posts/:id
```

Updates the content of a post. **Cannot update posts that have already been sent.**

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `website_id` | integer | Yes | The website ID (in the URL path) |
| `id` | integer | Yes | The post ID (in the URL path) |
| `content` | string or array | Yes | New post content. String or array of strings for threads |

### Code Examples

<Tabs>
<TabItem label="cURL">

```bash
curl -X PATCH https://my.poaster.app/v1/websites/1/posts/42 \
  -H "Authorization: Bearer po_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "content": ["Updated first tweet", "Updated second tweet in thread"]
  }'
```

</TabItem>
<TabItem label="Python">

```python
import requests

response = requests.patch(
    "https://my.poaster.app/v1/websites/1/posts/42",

        "Authorization": "Bearer po_live_your_api_key",
        "Content-Type": "application/json",
    },
    json={
        "content": ["Updated first tweet", "Updated second tweet in thread"]
    },
)
print(response.json())
```

</TabItem>
<TabItem label="Ruby">


</TabItem>
</Tabs>

### Response

```json
{
  "success": true,
  "message": "Post updated successfully.",
  "post": {
    "id": 42,
    "content": ["Updated first tweet", "Updated second tweet in thread"],
    "status": "pending"
  }

```

### Errors

| Status | Cause |
|--------|-------|
| `401` | Invalid or missing API key |
| `403` | Post belongs to another user's website |
| `422` | Post already sent, or content is empty |

## Post Object

| Field | Type | Description |
|-------|------|-------------|
| `id` | integer | Unique identifier |
| `content` | array | JSON array of strings (supports multi-part threads) |
| `status` | string | `pending`, `approved`, `rejected`, or `sent` |
| `post_type` | integer | Post type (default: 0) |
| `sent_at` | datetime | When the post was sent (null if unsent) |
| `x_tweet_id` | string | X/Twitter tweet ID after publishing |
| `webpage_id` | integer | Parent webpage ID |
| `created_at` | datetime | ISO 8601 timestamp |

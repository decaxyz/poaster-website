Poaster provides bulk endpoints for processing multiple posts in a single request. These are essential for automation workflows and AI agent integrations.

## Available Bulk Endpoints

| Endpoint | Method | Action |
|----------|--------|--------|
| `/v1/websites/:id/posts/bulk_approve` | `PATCH` | Approve multiple posts |
| `/v1/websites/:website_id/posts/bulk_reject` | `PATCH` | Reject multiple posts |
| `/v1/websites/:website_id/posts/bulk_re_enqueue` | `PATCH` | Re-enqueue multiple posts |
| `/v1/websites/:website_id/posts/send_now` | `POST` | Send multiple posts now |

## Request Format

All bulk endpoints accept a `post_ids` array:

```json
{
  "post_ids": [42, 43, 44, 45, 46]
}
```

## Example: Bulk Approve and Send

A common workflow is to approve all pending posts and then send them:

<Tabs>
<TabItem label="cURL">

```bash
# Step 1: Bulk approve
curl -X PATCH https://my.poaster.app/v1/websites/1/posts/bulk_approve \
  -H "Authorization: Bearer po_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"post_ids": [42, 43, 44]}'

# Step 2: Send them
curl -X POST https://my.poaster.app/v1/websites/1/posts/send_now \
  -H "Authorization: Bearer po_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"post_ids": [42, 43, 44]}'
```

</TabItem>
<TabItem label="Python">

```python
import requests

BASE = "https://my.poaster.app"
HEADERS = {
    "Authorization": "Bearer po_live_your_api_key",
    "Content-Type": "application/json",
}

post_ids = [42, 43, 44]

# Step 1: Bulk approve
requests.patch(f"{BASE}/v1/websites/1/posts/bulk_approve", headers=HEADERS, json={"post_ids": post_ids})

# Step 2: Send them
requests.post(f"{BASE}/v1/websites/1/posts/send_now", headers=HEADERS, json={"post_ids": post_ids})
```

## Best Practices

- **Batch size**: Keep batches under 50 post IDs per request for reliability
- **Verify status**: Only approved posts can be sent. Make sure bulk_approve succeeds before calling send_now
- **Idempotency**: Approving an already-approved post is safe — it's a no-op
- **Error handling**: If one post in a batch fails, the rest still process. Check individual post statuses after bulk operations
- **Rate limiting**: Space bulk requests at least 1 second apart

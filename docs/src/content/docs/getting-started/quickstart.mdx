Make your first API call to Poaster in four steps.

## Step 1: Create an Account

Sign up at [my.poaster.app/signup](https://my.poaster.app/signup). You'll need a Starter ($10/mo) or Agency ($299/mo) plan for API access — the Basic plan limits you to 1 website and 10 posts.

## Step 2: Generate an API Key

1. Log in to [my.poaster.app](https://my.poaster.app)
2. Go to **Settings** → **API Keys**
3. Enter a name (e.g., "My Integration") and click **Create**
4. **Copy the key immediately** — it's shown only once

Your API key starts with `po_live_` and looks like:

```
po_live_a1B2c3D4e5F6g7H8i9J0...
```

## Step 3: Create a Website

<Tabs>
<TabItem label="cURL">

```bash
curl -X POST https://my.poaster.app/websites \
  -H "Authorization: Bearer po_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "website": {
      "base_url": "https://myblog.substack.com",
      "website_type": "substack"
    }
  }'
```

</TabItem>
<TabItem label="Python">

```python
import requests

response = requests.post(
    "https://my.poaster.app/websites",
    headers={
        "Authorization": "Bearer po_live_your_api_key",
        "Content-Type": "application/json",
    },
    json={
        "website": {
            "base_url": "https://myblog.substack.com",
            "website_type": "substack",
        }
    },
)

print(response.status_code)
print(response.json())
```

</TabItem>
<TabItem label="Ruby">

```ruby
require 'net/http'
require 'json'

uri = URI('https://my.poaster.app/websites')
request = Net::HTTP::Post.new(uri, 'Content-Type' => 'application/json')
request['Authorization'] = 'Bearer po_live_your_api_key'
request.body = {
  website: {
    base_url: 'https://myblog.substack.com',
    website_type: 'substack'
  }
}.to_json

response = Net::HTTP.start(uri.hostname, uri.port, use_ssl: true) do |http|
  http.request(request)
end

puts response.code
puts response.body
```

</TabItem>
<TabItem label="JavaScript">

```javascript
const response = await fetch("https://my.poaster.app/websites", {
  method: "POST",
  headers: {
    Authorization: "Bearer po_live_your_api_key",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    website: {
      base_url: "https://myblog.substack.com",
      website_type: "substack",
    },
  }),
});

console.log(response.status);
const data = await response.json();
console.log(data);
```

</TabItem>
</Tabs>

Note the website ID from the response — you'll need it for the next step.

## Step 4: Create a Post

<Tabs>
<TabItem label="cURL">

```bash
curl -X POST https://my.poaster.app/websites/1/posts \
  -H "Authorization: Bearer po_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Just published a new article on building AI-powered tools. Check it out! 🚀"
  }'
```

</TabItem>
<TabItem label="Python">

```python
import requests

response = requests.post(
    "https://my.poaster.app/websites/1/posts",
    headers={
        "Authorization": "Bearer po_live_your_api_key",
        "Content-Type": "application/json",
    },
    json={
        "content": "Just published a new article on building AI-powered tools. Check it out! 🚀"
    },
)

print(response.json())
```

</TabItem>

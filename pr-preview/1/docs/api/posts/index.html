Posts

Posts are the core content object in Poaster. Each post contains text (or a thread of text parts) and moves through statuses: pending → approved → sent. The API gives you full control over this lifecycle.

Post Statuses

Section titled “Post Statuses”
StatusDescription
pendingNewly created, awaiting review
approvedApproved and queued for publishing
rejectedRejected, will not be published
sentSuccessfully published to social media

Create a Post

Section titled “Create a Post”

Creates a new post. If the website has auto_approve_posts enabled, the post is automatically approved.

Parameters

Section titled “Parameters”
NameTypeRequiredDescription
website_idintegerYesThe website ID (in the URL path)
contentstringYesThe post text. Wrapped in an array internally to support threads
urlstringNoSource URL for the post. Defaults to the website’s base_url

Code Examples

Section titled “Code Examples”
  • cURL
  • Python
  • Ruby
  • JavaScript

Response

Section titled “Response”

Errors

Section titled “Errors”
StatusCause
401Invalid or missing API key
403Website belongs to another user
422Content is blank

Update a Post

Section titled “Update a Post”

Updates the content of a post. Cannot update posts that have already been sent.

Parameters

Section titled “Parameters”
NameTypeRequiredDescription
website_idintegerYesThe website ID (in the URL path)
idintegerYesThe post ID (in the URL path)
contentstring or arrayYesNew post content. String or array of strings for threads

Code Examples

Section titled “Code Examples”
  • cURL
  • Python
  • Ruby
  • JavaScript

Response

Section titled “Response”

Errors

Section titled “Errors”
StatusCause
401Invalid or missing API key
403Post belongs to another user’s website
422Post already sent, or content is empty

Reject a Post

Section titled “Reject a Post”

Rejects a post. It will not be published.

Parameters

Section titled “Parameters”

Same as Approve.

Code Examples

Section titled “Response”

Re-enqueue a Post

Section titled “Re-enqueue a Post”

Moves a post back to approved status and clears its sent_at timestamp and x_tweet_id. Useful for re-publishing a post.

Parameters

Section titled “Parameters”

Same as Approve.

Code Examples

Section titled “Code Examples”
  • cURL
  • Python
  • Ruby
  • JavaScript

Send a Post Now

Section titled “Send a Post Now”

Immediately sends an approved post to all connected share accounts. The post must not have already been sent. The website must have at least one share account connected.

Parameters

Section titled “Parameters”

Same as Approve.

Code Examples

Section titled “Code Examples”
  • cURL
  • Python
  • Ruby
  • JavaScript

Errors

Section titled “Errors”
StatusCause
401Invalid or missing API key
422Post already sent
422No share accounts connected to the website

Send Multiple Posts Now

Section titled “Send Multiple Posts Now”

Sends multiple approved posts immediately. Same constraints as individual send.

Parameters

Section titled “Parameters”
NameTypeRequiredDescription
website_idintegerYesThe website ID (in the URL path)
post_idsarrayYesArray of post IDs to send

Code Examples

Section titled “Code Examples”
  • cURL
  • Python
  • Ruby
  • JavaScript

Send Posts Now and Return

Section titled “Send Posts Now and Return”

Same as send_now but returns to the compose page in the browser UI. Identical behavior for API requests.

Parameters

Section titled “Parameters”

Same as Send Multiple Posts Now.

Section titled “Bulk Approve”

Approves multiple posts at once.

Parameters

Section titled “Parameters”
NameTypeRequiredDescription
website_idintegerYesThe website ID (in the URL path)
post_idsarrayYesArray of post IDs to approve

Code Examples

Section titled “Code Examples”
  • cURL
  • Python

Bulk Reject

Section titled “Bulk Reject”

Rejects multiple posts at once. Same parameters and format as Bulk Approve.

Bulk Re-enqueue

Section titled “Bulk Re-enqueue”

Moves multiple posts back to approved status. Same parameters and format as Bulk Approve.

Post Object

Section titled “Post Object”
FieldTypeDescription
idintegerUnique identifier
contentarrayJSON array of strings (supports multi-part threads)
statusstringpending, approved, rejected, or sent
post_typeintegerPost type (default: 0)
sent_atdatetimeWhen the post was sent (null if unsent)
x_tweet_idstringX/Twitter tweet ID after publishing
webpage_idintegerParent webpage ID
created_atdatetimeISO 8601 timestamp

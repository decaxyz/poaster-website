Websites

Websites represent publishing destinations where your content appears. Each website is connected to share accounts (X, LinkedIn) that publish its posts.

Create a Website

Section titled “Create a Website”

Creates a new website and enqueues it for AI evaluation. Poaster’s AI will analyze the site and generate social media posts from its content.

Parameters

Section titled “Parameters”
NameTypeRequiredDescription
website[base_url]stringYesThe URL of the website (e.g., https://myblog.substack.com)
website[website_type]stringYesType of website: generic or substack

Code Examples

Section titled “Code Examples”
  • cURL
  • Python
  • Ruby
  • JavaScript

Response

Section titled “Response”

On success, the website is created and queued for evaluation. The response redirects to the website page (for browser requests) or returns JSON (for API requests).

Errors

Section titled “Errors”
StatusCause
401Invalid or missing API key
403Plan limit reached for websites
422Validation error (missing base_url or website_type)

Retry Website Evaluation

Section titled “Retry Website Evaluation”

Re-queues a website for AI evaluation. Useful when the initial evaluation failed or you want to re-analyze the site.

Parameters

Section titled “Parameters”
NameTypeRequiredDescription
idintegerYesThe website ID (in the URL path)

Code Examples

Section titled “Code Examples”
  • cURL
  • Python
  • Ruby
  • JavaScript

Errors

Section titled “Errors”
StatusCause
401Invalid or missing API key
403Website belongs to another user
404Website not found

Delete a Website

Section titled “Delete a Website”

Permanently deletes a website and all its associated webpages and posts. This action is irreversible.
